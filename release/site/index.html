OM

Private messaging that nobody operates for you

OM is an open-source, operatorless, end-to-end-encrypted messenger. Your conversations belong to you and your devices, not to a company that could read, sell or lose them.

A SeedLife project. Protect life. Seed it.

Beta

OM is a beta. It is not independently audited, it makes no security claims, and it may lose data. Try it, but do not rely on it for anything private or important.

What OM is for

  • End-to-end encrypted: only the people in a conversation can read it.
  • Operatorless: there is no company account to sign up for and no central service that has to stay online.
  • Open source: anyone can read, check and run the code.
  • Made for ordinary people: no technical vocabulary needed.

Install OM as an app

OM works in your browser, and it is better installed. It then opens in its own window and works like any other app.

  • iPhone and iPad (Safari): tap the Share button, then Add to Home Screen.
  • Android (Chrome): open the menu, then Install app.
  • Desktop (Chrome, Edge): choose Install in the address bar or the browser menu.

Run your own copy

OM is built so that you do not have to trust anyone's server, including ours. You can get the code and host your own copy of this app.
